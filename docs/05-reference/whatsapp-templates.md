# WhatsApp templates

> 22 Meta-submittable templates. Each corresponds to an event in `02-events.md`
> with the whatsapp channel. Templates must be submitted to Meta Business
> Manager for approval before production use. Categories: utility,
> authentication, marketing. Variables use `{{1}}, {{2}}, {{3}}` per Meta spec.

## Templates

### counsellor_assigned (utility)
Variables: 1=student first name, 2=counsellor full name
> Hi {{1}}, your EduNomad counsellor is {{2}}. They will message you within 4 working hours to schedule a call. Save this number.

### counsellor_message_summary (utility)
